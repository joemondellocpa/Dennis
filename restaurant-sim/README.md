# Non-Shitty Restaurant Tycoon

A browser demo for restaurateurs. Describe the restaurant (room, service, menu, non-negotiables), watch a dinner service run from above, then read the night's books and the advice.

Open `index.html` in a browser. No install, no build.

- `js/data-menus.js` menus for the five cuisines
- `js/state.js` defaults, presets, guest types, pricing helpers
- `js/layout.js` room geometry and table placement
- `js/sim.js` the dinner service and the nightly P&L
- `js/advice.js` end-of-night recommendations
- `js/render.js`, `js/ui.js` drawing and screens
